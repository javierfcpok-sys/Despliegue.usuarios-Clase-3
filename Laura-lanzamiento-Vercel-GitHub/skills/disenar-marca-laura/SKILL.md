# Diseñar marca Laura

Leer references/marca.md antes de crear componentes. Mantener una identidad cálida, serena y administrativa para una doctora y una asistente. No inventar acreditaciones, cifras de éxito ni garantías clínicas.

1. Identificar la tarea principal y el soporte: panel, mensaje o material de marca.
2. Aplicar los tokens del documento de marca. Usar tipografía de sistema y recursos SVG propios para evitar dependencias remotas.
3. Diseñar primero jerarquía, acciones y estados; añadir decoración solamente si favorece orientación.
4. Escribir microcopy breve en español de México, amable y sin culpar al paciente. Distinguir solicitud de cambio de cita reprogramada y envío de entrega.
5. Comprobar contraste de texto normal >= 4.5:1, foco visible, etiquetas, lectura a 390 px y estados identificables sin depender del color. Corregir tokens si fallan.
6. Entregar tokens CSS, componente aplicado y una justificación breve de su relación con continuidad y calma. Identificar toda integración simulada de forma permanente.
